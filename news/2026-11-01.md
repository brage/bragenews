# News Digest — 2026-11-01

## Databricks

- **[Lakeflow Pipelines Run-as Groups](https://docs.databricks.com/aws/en/release-notes/product/2026/october)** — Databricks added the ability to set pipeline run-as identity to an account group (Oct 5, 2026), allowing teams to collectively own pipelines and control permissions without relying on individual users. This improvement strengthens team collaboration and governance for data pipeline management.

- **[Excel Add-in Scheduled Refresh](https://docs.databricks.com/aws/en/release-notes/product/2026/october)** — Databricks introduced scheduled automatic refreshes for data imported into Microsoft Excel (Oct 1, 2026, Public Preview). This feature streamlines the workflow for business users who rely on Excel for reporting while pulling live data from Databricks.

- **[Power BI ADBC Driver Now Generally Available](https://docs.databricks.com/aws/en/release-notes/product/2026/october)** — The Arrow Database Connectivity (ADBC) driver for the Databricks connector for Power BI reached general availability on October 15, 2026. ADBC is now the default driver for new Power BI Desktop and service connections, improving performance and compatibility.

- **[DataFrame Caching on Serverless Compute](https://docs.databricks.com/aws/en/release-notes/product/2026/october)** — Databricks moved DataFrame caching on serverless compute to Public Preview on October 23, 2026. This feature can significantly reduce query latency and compute costs for frequently accessed data in Fabric and lakehouse workloads.
